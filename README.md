# Axentra

Personal career operations app: job applications, grounded resume tailoring, prep drills, voice mock interviews, habits, and a career readiness score.

- [`frontend-design.md`](frontend-design.md) — UI stack, tokens, design rules

- Node 24 (see `.nvmrc`)
- Docker (PostgreSQL 16 + Redis 7)

Setup and run instructions land with plan steps 0.2–0.5.
